# 打卡页逻辑优化设计方案

## 1. 背景与问题

当前"记录小行星"（打卡页）包含 3 个 tab：XP 记录、学习记录、财务记录。其中学习记录和财务记录允许用户手动添加作业和财务流水，这与"作业和金钱应该是自动的"的设计原则矛盾。

## 2. 核心设计原则

**系统设置是规则中枢，各星球是执行者。**

```
系统设置（定义规则）
    ├── 任务规则（23 条 XP 规则）
    │   ├── 作业类（自动发放）→ 知识星球使用
    │   └── 手动类（手动打卡）→ 记录小行星使用
    ├── 财务分类（6 收入 + 3 支出）→ 财富星球使用
    └── 科目配置 → 知识星球使用
```

## 3. 具体改造方案

### 3.1 记录小行星（打卡页）— 删减

**目标**：只保留手动打卡功能，去掉不相关的录入入口。

**改动**：
- 去掉"学习记录"tab 及其面板（`#panel-study`）
- 去掉"财务记录"tab 及其面板（`#panel-money`）
- 只保留"XP 记录"tab，聚焦手动打卡
- XP 记录表单中只展示系统设置中"手动"类的规则（兴趣爱好、身体成长、能力成长等）
- 日常打卡按钮保持不变

### 3.2 知识星球 — 新增"添加作业"功能

**目标**：在知识星球页面增加作业录入入口，用户在此添加作业。

**改动**：
- 在知识星球页面（`renderStudy` 区域）增加"添加作业"按钮
- 点击后弹出作业录入表单，包含：
  - 科目选择器（语文/数学/英语/科学/道德与法治/信息科技/体育/音乐）
  - 作业类型选择（日常作业/暑假作业/假期作业/家庭作业）
  - 作业标题/内容输入
  - 能力模块多选
  - 截止日期
  - 提交按钮
- 提交后自动写入 `study.json`（`DataStore.addStudyRecord`）
- 自动匹配系统设置中对应作业类型的 XP 规则
- 首页今日任务自动拉取

### 3.3 财富星球 — 保持不变

- 已有完整记账功能，不需要改动
- 记账时使用系统设置中定义的财务分类
- 财务复盘功能保留

### 3.4 首页今日任务 — 保持不变

- 自动从 `study.json` 拉取今日到期的作业
- 自动拉取待确认的成长记录
- 不需要手动添加

### 3.5 系统设置 — 保持不变

- 任务规则面板中，作业类规则标注"自动发放"
- 手动类规则按原有展示
- 财务分类保持原有配置

## 4. 数据流

```
知识星球添加作业
    → DataStore.addStudyRecord(study.json)
    → 首页今日任务自动拉取
    → 作业完成时自动发放 XP（匹配任务规则）

记录小行星手动打卡
    → DataStore.addXpRecord(xpRecords)
    → 直接写入 XP 记录
    → 首页能量星球更新

财富星球记账
    → DataStore.addFinanceRecord(finance.json)
    → 使用系统设置的财务分类
    → 财务复盘时自动发放 XP
```

## 5. 涉及文件

| 文件 | 改动 |
|------|------|
| `index.html` | 打卡页去掉学习/财务 tab；知识星球添加"添加作业"功能 |
| `data/study.json` | 不变（数据格式已有） |
| `data/xpSources.json` | 不变（规则配置已有） |
| `data/finance.json` | 不变 |
| `system-settings.html` | 不变 |

## 6. 实现要点

### 打卡页（index.html）
- 在 `#view-data-entry` 中删除 `#panel-study` 和 `#panel-money` 的 HTML
- 在 `initDataEntry()` 中删除 `#submitStudy`、`#batchSubmitStudy`、`#submitMoney` 的事件绑定
- tab 栏只保留"XP 记录"一个按钮

### 知识星球（index.html）
- 在 `renderStudy()` 中增加"添加作业"按钮
- 复用已有的作业录入表单逻辑（`addStudyRecord`）
- 表单样式与现有设计系统一致
